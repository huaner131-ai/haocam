# SDK drop-in directory

Proprietary SDK distributions are NEVER committed to this repository.

  facebetter/   unzip the Facebetter desktop C++ SDK here (Phase 2)
  openmakeup/   OpenMakeupSDK web distribution (Phase 3)
  snap/         Camera Kit web assets/config (Phase 4)

Each subdirectory is gitignored except its README. Provide credentials via
the HaoCam settings file only (docs/SDK_INTEGRATION.md).
